
# Flipkart Descriptive Analytics Report

## Project Overview
This project focuses on analyzing Flipkart's e-commerce sales behavior using a synthetic dataset covering 30 days of order activity from 1 September to 30 September 2026.

The project uses descriptive analytics to understand product popularity, daily order trends, peak ordering hours, customer ratings, return rates, state-wise engagement, and payment preferences.

## Objectives
- Identify the most sold products.

## Dataset Information
The project uses a synthetic dataset generated for academic purposes.

- **Raw Records:** 5,280
- **Cleaned Records:** 5,179
- **Analysis Period:** 30 Days
- **Products:** 12
- **Categories:** 7
- **Indian States:** 8
- **Payment Methods:** 5

The dataset includes order dates, products, categories, prices, discounts, quantities, payment methods, customer ratings, order status, locations, and device information.

**Note:** This is simulated data and does not represent actual Flipkart customer transactions.

## Data Cleaning and Preparation
The following steps were performed to prepare the data:

1. Removed duplicate records.
2. Standardized product names, locations, and payment methods.
3. Filled missing customer ratings using category median ratings.
4. Removed records with missing location information.
5. Corrected data types.
6. Removed invalid ratings and non-positive quantities.
7. Created additional fields for revenue, returned orders, and delivered orders.
